TraverseBD Backend API Documentation

Spring Boot Backend - Supabase PostgreSQL + Storage
Version: 1.0 | Date: 23 November 2026 | Owner: Sifat Mazib

This document describes the REST API contract for frontend integration. Protected admin endpoints require a JWT returned by login or Google sign-in.

Base URL and Authentication

Local: http://localhost:8080
Production: https://<deployed-backend-domain>
Protected header: Authorization: Bearer <JWT>

The backend also sets an HTTP-only ADMIN_SESSION cookie for browser sessions. Cookie and bearer authentication are both accepted.

Authentication

MethodEndpointPurpose
POST/api/auth/loginPublic email/password login; returns JWT and profile.
POST/api/auth/googlePublic Google sign-in; account must already be provisioned.
POST/api/auth/logoutClear the HTTP-only session cookie.

Login request

{"email":"admin@traversebd.local","password":"Admin@123456"}

Google request

{"idToken":"<Google ID token>"}

Authentication response

{"accessToken":"JWT","email":"admin@traversebd.local","role":"SUPER_ADMIN"}

JWTs expire after 60 minutes by default. The seed role is SUPER_ADMIN; normal staff are ADMIN.

Admin Users

MethodEndpointPurpose
GET/api/admin/usersSUPER_ADMIN list all admin users.
POST/api/admin/usersSUPER_ADMIN provision an ADMIN or SUPER_ADMIN account.
PUT/api/admin/users/{id}SUPER_ADMIN update role, email or active status.
DELETE/api/admin/users/{id}SUPER_ADMIN delete a user; last active Super Admin is protected.
{"email":"staff@example.com","password":"optional","role":"ADMIN"}

Packages

MethodEndpointPurpose
GET/api/public/packagesPublished packages; optional destinationId, categoryId, minPrice, maxPrice and durationDays.
GET/api/public/packages/{slug}Published package detail.
GET/api/admin/packagesAdmin list including drafts.
POST/api/admin/packagesAdmin create package.
PUT/api/admin/packages/{id}Admin update package.
DELETE/api/admin/packages/{id}Admin delete package.

Package contract

{"title":"Sundarbans 3 Day","slug":"optional","destinationId":"uuid","categoryId":"uuid",
"price":12500,"durationDays":3,"priceMode":"FIXED|STARTING_FROM",
"shortDescription":"Short","fullDescription":"Full","coverImageUrl":"https://...",
"status":"DRAFT|PUBLISHED","featured":true,"trending":false,
"items":[{"type":"included","text":"Transport","sortOrder":1},
         {"type":"activity","text":"Mangrove boat ride","sortOrder":2}]}

price is a whole BDT amount greater than zero. Package item types are not restricted.

Departures

MethodEndpointPurpose
GET/api/public/packages/{packageId}/departuresPublic package departures.
GET/api/admin/departuresAdmin list departures.
POST/api/admin/departuresAdmin create departure and seat totals.
PUT/api/admin/departures/{id}Admin update departure.
DELETE/api/admin/departures/{id}Admin delete departure.
{"packageId":"uuid","departureDate":"2026-12-10","totalSeats":30,
"bookedSeats":0,"priceOverride":null}

Booked seats must not exceed total seats. Departure management is manual; the API never creates a booking or reservation.

Publish Status Contract

Every public content type uses DRAFT or PUBLISHED. Public search, detail and list endpoints exclude drafts. Publishing or unpublishing is effective immediately.
