TraverseBD Backend API Documentation

Version: 1.0   Base URL: /api   Backend: Spring Boot 3.5 / Java 21 / Supabase PostgreSQL

This document defines the backend interfaces owned by Sifat Mazib for frontend and integration synchronization.

1. Authentication and Headers

Admin endpoints require an HTTP-only ADMIN_SESSION cookie or Authorization: Bearer <JWT>. JWTs expire after 60 minutes by default.

{ "Authorization": "Bearer eyJ..." }

2. Authentication APIs

MethodEndpointBody / ResultAccess
POST/api/auth/login{"email":"...","password":"..."}
Returns email, role and accessToken		Public
POST/api/auth/google{"idToken":"<Google ID token>"}
Email must already be provisioned		Public
POST/api/auth/logoutClears the HTTP-only session cookiePublic

12. Error Format

{"error":"VALIDATION_ERROR|CONFLICT|BAD_REQUEST","message":"Human-readable detail"}

Unauthenticated protected requests return 401 or 403. Draft resources are absent from public endpoints and sitemap data should be generated only from published records.
